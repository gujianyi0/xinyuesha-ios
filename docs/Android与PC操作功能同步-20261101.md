# Android／PC 通用操作同步 · 2026-11-01

按用户追加要求，将 iOS 已交付的通用操作同步到 Android 与 PC。

- 战报、聊天、玩家列表支持左右触摸切页，顶部标签同步；上下仍读当前列表，关闭重开保留页签。PC 增加底部可用鼠标拖动的切页滑块，保留顶部点选；新核心的两标签偏移模式沿用原导航。
- 记牌器已知手牌支持“全部／各玩家”筛选和分组，玩家 ID 区分同名，名称变化保留选择，实时刷新保持滚动位置，失去全部记录后退回“全部”。不确定记录不计入右侧确定数量。
- 同步星魂可见牌、Processing 交换与确认后排列的记录修正；只使用当前视角实际已知信息，不读取隐藏牌堆身份。
- 保留 Android 录像文件选择、各端背景导入等平台实现；无新增对局轮询。
