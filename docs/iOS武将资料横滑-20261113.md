# iOS 武将资料面板左右滑动 · 20261113.1

反馈 FB-0DX3XM（iOS，玩家字段为“最新版”）的正文、完整讨论和原始截图已核对。截图明确指向武将资料的技能、装备区、判定区、手牌区四个标签；提交时没有补充评论。

原版 PlayerDetail.qml 已有四页 SwipeView，但 interactive=false。此版本在自定义 CounterHost 中按面板创建事件接入横滑，并同步原版标签索引；只对 iOS 的四区资料页启用。适配器随资料页销毁，重复调用不重复连接。原版核心文件不改写。

本次 IPA 基于 20261108.2，保留已发布的明牌数量标记、管宁动作重放和隐藏零数量默认值。仅 CounterHost.qml、SocialHost.qml 的版本标题及 client-ui-revision 改变；原生程序、游戏核心与其他资源逐字节一致。Android、PC 不重发；工具整合包仍为旧版。
