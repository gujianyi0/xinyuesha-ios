# 20261027.1 牌堆明牌兼容修正

对应官网反馈 FB-EN6YR4（晋司马懿）和 FB-YYSBX7（OL 黄承彦），两条均填写 iOS、版本不清楚，无附件及补充讨论。已读的 Android 回车反馈不在本批修复范围。

- 鹰视：覆盖原版武将标记打开的 ViewPile。只在实际展示的正面牌与鹰视标记提供的牌列表匹配时记录顶牌；其他牌堆查看不会被推测为牌堆顶。
- 观虚：识别原版 PoxiModel 的 guanxu_exchange / Top 行，同时保留实际展示的目标手牌。整批换牌按先移出、后移入维护已知顺序，避免原追踪器依据最终牌堆长度反复重置。
- 权变：记录实际展示的顶牌，并在确认时使用实际排列结果维护剩余顶牌和将被获得的牌；取消不应用未确认排列。
- 移牌维护只使用已有已知位置、可见移牌、明确顶底及公开长度。没有读取隐藏牌堆身份或其他玩家的追踪器；不确定的内部暗移牌仍保守清除位置。
- 不增加空闲轮询。不涉及牌堆的移动不复制顺序表；原生程序及服务端校验核心保持前版。

共用负载三端同步。测试包含原版 KnownCardTracker 的观虚交换丢失复现、后续摸牌、暗牌位置失效、权变获得牌，以及实际 CounterHost 的看牌入口、隐藏牌拒绝和无空闲采集。测试夹具不代替 iPhone 完整游戏验收；交付后保留待真机复测状态。
