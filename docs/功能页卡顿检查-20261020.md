# 功能页持续卡顿修正 · 2026-10-20

用户确认 2026-10-19 07:20 Android 分发快照（本地提交 36aea4a，APK SHA256 0fcd6ad5…）及同批 PC 为稳定基线；后来 r3 在武将一览等操作仍感觉更卡。稳定包已保留，不用新包覆盖基线。

之前的优化只停止了对局/观战中的全树扫描，大厅和原版功能页仍每秒执行一次兼容遍历；好友大厅每半秒遍历一次房间控件。修正改为观察原版 StackView 页面切换、过渡完成和弹窗出现，定向适配当前页面/弹窗，跳过功能页的武将/卡牌网格。好友房间入口在页面切换和房间列表数量变化时重新挂接，邀请权限计时器只做轻量检查。PC 同时修正非列表 data 属性的遍历保护。

桌面 Qt 6.8.3，3500 节点固定场景：修正前 2.25 秒功能页停留触发 2 次全树遍历，事件循环最大间隔约 230–364 毫秒；大厅还触发约 5 次好友控件遍历。修正后大厅、功能页与返回功能页的持续遍历均为零。此为模拟场景，不是手机帧率，也不能证明所有用户卡顿已消失。原先每次扫描耗时未消失，而是避免在停留期间重复执行；大网格在单次导航适配时也跳过。
