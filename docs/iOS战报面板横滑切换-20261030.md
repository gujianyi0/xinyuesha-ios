# iOS 20261030.1 战报面板横滑切换

对应反馈 [FB-N8JBPZ](https://preview.gujianyi-web-preview.pages.dev/feedback/FB-N8JBPZ/) 及聊天中补图。完整正文要求左右滑动切换“战报／聊天／玩家列表”，平台为 iOS，版本不清楚；原条目没有附件及补充讨论。

原版房间抽屉的 SwipeView 设置为 `interactive: false`。iOS 界面兼容层仅识别与三个原标签对应的横向容器，开启其原生横向滑动，并将当前页同步回顶部标签。原标签到页面的绑定、竖向列表、输入和关闭记忆继续使用原版流程。针对较新核心的双标签偏移模式保持原导航。

兼容连接由页面对象持有，每个实例只安装一次；仅在抽屉创建／显示的既有界面事件中适配，没有新增定时轮询。Android、PC 负载及安装包未改动；iOS 原生程序和服务端校验核心保持前版。

新增实际触摸回归使用原版 RoomPage 抽屉、ViewSwitcher、LogEdit 和 AvatarChatBox，覆盖左右往返、首尾边界、顶部标签点按、竖向翻阅与实时消息、缩放、关闭重开、输入发送及重复连接检查。基础核心与当前本地服务器核心均通过；旧基础核心已有的聊天气泡宽度警告单独记录为测试前基线，未当作本功能引入的错误忽略其他警告。
