# 房间入口、角色语音与好友网络 · 2026-10-22

## 最终行为

- 好友入口等待当前房间原版按钮有效布局后再显示。结算、继续游戏及返回房间时清除旧锚点，跟随实际等待房间和缩放变化，避免先出现在原版界面上、点击后才归位。
- 聊天输入行新增“角色”。列表读取 `Fk:getAllGenerals()` 的当前启用将池，隐藏武将不列出；选择后将已下载角色语音放在语音列表前部。原有语音保留，切换房间重选，发送前再次检查可用性。
- 沿用现有 Chat type=2 协议。角色专属语音携带所选角色，默认语音保留性别规则及 1.5 秒冷却，没有修改服务器规则。尚未向其他真人玩家发送测试语音。
- 原入口与备用入口通过绑定连接同一好友服务，沿用身份和数据。只对登录和同步的网络失败重试一次；401/429 按业务规则处理。好友申请、邀请、预约等写操作不自动重放，退出取消旧请求。

## iOS 当前故障

反馈者能进入游戏，但 Safari 无法打开 `freekill-friends.pages.dev` 和 `xinyuesha-friends-api.pages.dev`。安卓可收到“接口不存在”或“好友服务登录已失效”，这说明该安卓网络已到达服务；这些业务响应属于预期，并非网页坏了。

两个入口都是 Cloudflare 提供的 pages.dev 域名，目前没有自有域名。无法仅凭这些反馈判断是 DNS、Wi-Fi、运营商路径还是手机设置；也不能归因于所有 iOS。需在同一台 iPhone 关闭 Wi-Fi 后测试手机流量并记录 Safari 的实际错误。应用增加备用入口不能保证浏览器也不可达的网络恢复，因此本项仍未解决。
