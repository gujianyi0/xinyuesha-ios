# iOS 移植改动说明

> 目标：让 FreeKill 0.5.25 的 Qt/QML/Lua 客户端在 iOS 16+ 真机上运行，并保留
> 「新月杀测试版」的全部运行时改动。
>
> 基线：`C:\Users\c2115\Documents\ChatGPT\other\work\freekill-card-counter\upstream\FreeKill`
> （C++ 源码）+ `deepseek/pc/新月杀测试版/FreeKill-release`（运行时 QML/Lua/资源）。

## 一、C++ 启动适配

### `src/freekill.cpp`

- `copyPath` 从 `Q_OS_ANDROID` 扩展到 `Q_OS_IOS`。
- 新增 `installFkAssetsIOS` / `copyPathIOS`：
  - iOS 的 `.app` 是只读的，首次启动把 `FreeKill.app/res` 复制到
    `Documents/FreeKill`，然后 `QDir::setCurrent` 过去；
  - 先复制除 `fk_ver` 外的全部文件，最后复制 `fk_ver` 作为完成标记；
  - 首次/中断安装使用“同尺寸跳过”续传，更新版本则完整覆盖；
  - 复制完成后把数据目录标记为不进入 iCloud 备份。
- 启动分支新增 `#elif defined(Q_OS_IOS)`：
  - `QLocale::system()` 取语言；
  - 不创建 `QSplashScreen`（iOS 用 LaunchScreen.storyboard，QWidget 窗口在
    iOS 上也不合适）；
  - 复制运行时后再打开 `freekill.server.log`。
- 日志消息处理器在 `log_file` 为空时不再构造 `QTextStream`，避免 iOS 启动早期
  尚未打开日志时崩溃。
- 安装 `fkIosPrepare()`（音频会话 / 屏幕常亮）。
- `OS` 上下文属性新增 `"iOS"`，供 QML 判断移动端。

### `src/pch.h`

- `DESKTOP_BUILD` 不再对 iOS 定义（它只用于 Windows 窗口图标）。

### `src/core/util.cpp`

- `GetDeviceUuid()` 在 iOS 上不能用硬件序列号（Apple 禁止）。改为用
  `QSettings("cui.freekill", "FreeKill")` 保存一个随机 UUID，首次生成、后续
  复用；卸载才会重置。

### `src/core/packman.cpp`

- CA 证书路径 `./certs` 对 iOS 也生效（证书目录从 Android APK 里提取，含 367
  个 hashed CA 文件）。
- iOS 运行时里的 `packages/freekill-core` 是**文件快照**（不含 `.git`）：本工程
  `shouldUseCore()` 固定 false，不需要 git 更新；`packages/packages.db` 保留
  freekill-core 记录，`sanitize_package_db` 不会删除它。PC 版的 `.git` 不上传
  到 iOS 仓库，避免被 Git 当成嵌套子模块。
- `shouldUseCore()` 在 iOS 上直接返回 `false`：
  - 本工程把带 card-counter / SocialHost / 故剑遗的 `Fk`、`LunarLtk`、
    `lua`、`ltk` 放在运行时根目录；
  - 如果加载 `packages/freekill-core/Fk/main.qml`（上游原版），这些改动会全部
    丢失。PC 版实际也是走根目录（core 的 pinned commit 判定为不更新），iOS
    直接固定这个行为，避免服务器后续更新 core 后界面“变回原版”。

### `src/ui/qmlbackend.cpp`

- `askFixResource()` 的平台判断加入 iOS（资源损坏时的“修复资源”提示可用）。

### `src/platform/ioshelper.{h,mm}`

- `fkIosPrepare()`：`AVAudioSessionCategoryPlayback` + 激活音频会话 +
  `idleTimerDisabled = YES`。
- `fkIosExcludeFromBackup()`：给 `Documents/FreeKill` 设置
  `NSURLIsExcludedFromBackupKey`。

## 二、QML 适配（runtime/）

| 文件 | 改动 |
|---|---|
| `Fk/main.qml` | `androidMode` → `mobileMode`，判断条件加 `Cpp.os === "iOS"` |
| `card-counter/client-shell/main.qml` | 同上 |
| `Fk/Pages/Common/Init.qml` | “修复资源”入口对 iOS 可见 |
| `LunarLtk/Pages/GeneralDetailPage.qml` | 删除未使用的 `QtQuick.Controls.FluentWinUI3` import（iOS 的 Qt 不提供 Windows 风格插件） |

## 三、构建系统

### 顶层 `CMakeLists.txt`

- Qt 组件列表按平台拆分：iOS 不查找 `LinguistTools`（`.qm` 直接使用 runtime
  里预编译好的文件）。
- iOS 不执行 `find_package(OpenSSL/SQLite3)`，改用 `ios-deps/` 里的静态库和
  iOS SDK 的 sqlite3。
- iOS 的 `FreeKill` 目标设置：
  - `MACOSX_BUNDLE TRUE`、`Info.plist.in`；
  - bundle id `com.cui.freekill.ios`；
  - `IPHONEOS_DEPLOYMENT_TARGET=16.0`、`ARCHS=arm64`、仅 iphoneos；
  - `CODE_SIGNING_ALLOWED=NO`（CI 产出未签名 IPA）。
- POST_BUILD：
  - `runtime/` → `FreeKill.app/res`
  - `ios/bundle/` → `FreeKill.app/`（AppIcon PNG）
  - `ibtool` 编译 `LaunchScreen.storyboard` → `LaunchScreen.storyboardc`
- 新增 `FreeKillIosImports` 这个“假 QML 模块”（`ios/IosImports.qml`），让
  `qmlimportscanner` 看到所有 Qt 模块；配合 `qt_import_qml_plugins` 在静态
  Qt 构建里把 QtQuick / Controls / Material / Multimedia / GraphicalEffects
  等 QML 插件链接进可执行文件。

### `src/CMakeLists.txt`

- `platform/ioshelper.mm` 加入源列表（跳过 PCH）。
- SoLoud 在 iOS 上编为 **STATIC**（桌面仍是 SHARED）。
- 移除 iOS 的 `Qt6::OpenGL` 链接（iOS 用 Metal + RHI；代码没有直接使用
  QtOpenGL）。
- 新增 `elseif (IOS)` 依赖分支：
  - `ios-deps/lib/liblua54.a`、`libcrypto.a`、`libssl.a`、`libgit2.a`；
  - `sqlite3`、`z`、`iconv` 用 `find_library`；
  - AVFoundation/UIKit/AudioToolbox/CoreAudio/CoreFoundation/Security 框架；
  - 头文件目录 `ios-deps/include`、`ios-deps/include/lua`。

### `ios/IosImports.qml`

列出运行时会用到的 Qt 模块：

```
QtQuick, QtQuick.Window, QtQuick.Templates, QtQuick.Controls,
QtQuick.Controls.Material, QtQuick.Layouts, QtQuick.Dialogs,
QtQuick.Shapes, Qt.labs.qmlmodels, QtQml.WorkerScript,
QtMultimedia, Qt5Compat.GraphicalEffects
```

本地模块 `Fk`、`LunarLtk`、`Spine` 不在里面——它们从可写运行时目录按
`qmldir` 加载。

## 四、依赖版本

| 依赖 | 版本 | 说明 |
|---|---|---|
| Qt for iOS | 6.8.3 | 最低 iOS 16；需 qtmultimedia、qt5compat、qtshadertools |
| Lua | 5.4.8 | 源码已放在 `thirdparty/lua`，`LUA_USE_IOS` |
| OpenSSL | 3.5.1 | 静态、`no-shared/no-tests/no-docs/no-asm`，iOS arm64 |
| libgit2 | 1.9.7 | 静态、OpenSSL HTTPS、无 SSH、内置 regex/zlib |

| SoLoud | 仓库自带 | 静态，miniaudio/CoreAudio |

## 五、首次构建最可能踩的坑

1. **Qt 组件缺失**：`aqt` 必须装 `qtmultimedia qt5compat qtshadertools`；
   否则 `find_package(Qt6)` 或 QML 插件链接会失败。
2. **libgit2/OpenSSL 架构**：必须都是 arm64 + iphoneos，不能混入 macOS
   Homebrew 的 x86_64/arm64-macOS 库。`build_deps.sh` 使用
   `CMAKE_SYSTEM_NAME=iOS` 和 iPhoneOS SDK。
3. **静态 QML 插件**：如果启动时报 `module "QtQuick.Controls" is not
   installed`，说明 `IosImports.qml` 没被扫描到，或漏了某个 import；在
   `ios/IosImports.qml` 补上对应模块后重新 configure。
4. **LaunchScreen**：`ibtool` 编译失败会让构建失败；如果只是警告，检查
   `FreeKill.app/LaunchScreen.storyboardc` 是否存在。`Info.plist` 的
   `UILaunchStoryboardName` 指向它，缺失会导致启动黑屏/崩溃。
5. **资源复制慢**：首次启动 79MB/三千多个文件，可能需要几秒；已做“同尺寸
   跳过”续传，第二次启动直接跳过。
6. **Spine 骨骼**：`.qsb` 由 `qt_add_shaders` 生成，默认包含 MSL 12；iOS
   走 Metal 应该可用。若黑屏/错位，先确认 `spine*.qsb` 在 app 资源里，
   再尝试 `QSG_RHI_BACKEND=opengl`。
7. **包名/签名**：bundle id 固定 `com.cui.freekill.ios`。免费 Apple ID 签名
   时如果提示 bundle id 冲突，改 `CMakeLists.txt` 的 `FK_IOS_BUNDLE_ID`
   重新构建。
8. **`Q_OS_IOS` 宏**：Qt 6 定义；不要用 `TARGET_OS_IPHONE` 混写。
