# iOS 后续界面反馈 · 2026-10-20

按用户指定顺序，先完成记牌器大牌池滑动性能候选包并同步本地与 GitHub 下载，再处理以下反馈。性能批源码 `e857cfc`，对应云端测试运行 `39303753245`。

## 本批修正

- 退出大厅：取消固定 40 高度，使用与同类 Material 按钮相同的隐式高度；补齐顶部对齐、最小宽度和一致字号。Qt 6.8.3 测试中两者高度均为 52 逻辑像素、顶部位置为 16；这不等于任意设备都使用固定物理像素高度。
- 记牌器输入：紧凑 TextField 不再使用 Material 浮动占位标签，设定垂直居中与零上下内边距。聚焦输入时受测光标 y=8、高度 12，位于高度 28 的输入框内。实际 iPhone 键盘与缩放下的位置仍待真机验收。
- 英文目标：在当前核心 UI 的 `PhotoModel.updateTargetTip` 内创建已经翻译的新对象列表。Qt 6.8 下遍历 QVariantList 后原地修改其元素，会修改临时包装而未发布原模型变更。回归测试从原始 `draw1`、`liexiangbigger` 复现未翻译显示，修正后收到中文结果；翻译仍由游戏已有的 `Ltk.processPrompt` 完成，不硬编码技能文案。

目标提示修正放在 iOS 自有的 UI 生成层中，随实际核心生成界面，保留下载的核心源文件及其校验输入原样。本批需要重新编译 iOS 原生程序，不能把旧 Mach-O 的仅换资源包声称为已包含此项。

## 忠胆英杰的无懈可击

核对主力服先前公布的 `gamemode` 提交 `ba1053ef227e2c11eb997e6464995609ae00189f`，文件 `pkg/gamemodes/vanished_dragon.lua`：

- 模式说明列出金蝉脱壳替换无懈可击。
- `build_draw_pile` 先调用普通牌池构建，随后将 `nullification` 等黑名单牌从 draw 移入 void，并加入包括 `crafty_escape` 在内的白名单牌。它没有因为选择更多扩展包而跳过这一步。

因此，在这份模式规则中普通无懈本来不在初始牌堆，记牌器不应把它强行加回。若技能只从当前牌堆按名称取牌，也无法取得已移出的普通无懈；未在远程玩家对局中替用户发动技能，不能将这一规则核对描述成势董昭全部技能分支的实际验收。若服务器另有模式版本、衍生无懈或变更规则，应按当局实际同步牌池复核。
