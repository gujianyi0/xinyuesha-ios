# iOS 记牌器卡牌列表滑动修正

用户确认卡顿位置为记牌器内的卡牌列表，在军八、双阴全扩牌堆更明显。先交付这一批性能修正，随后处理退出大厅按钮、输入文字位置、无懈可击统计和英文目标文字；不能将后者尚未修复的现象写成已解决。

## 本次变化

- 卡牌目录与数量分离：只有目录或过滤结果改变时才替换 GridView 模型。数量刷新只更新显示绑定，保留可见卡牌对象与滚动位置。
- 拖动和惯性滑动期间暂停 500 毫秒快照轮询，停止后立即补齐；不暂停游戏消息和服务器通信。
- Lua 只为当前选中的卡牌生成花色、点数明细，其他牌保留原计数。无参数调用仍保留完整明细兼容行为。
- 卡图启用异步加载和有界缩略图尺寸；启用视图复用和有限预加载。
- 打开面板不再连续请求两次同一份快照。

## 验证

使用实际 CardCounter.qml、Qt 6.8.3 和 Lua 5.4，构造 300 种牌、900 张实体牌的大牌池：

| 检查项 | 原版 | 修正后 |
| --- | ---: | ---: |
| 20 次数量更新新建的卡牌显示项 | 420 | 0 |
| 同一段惯性滑动中的快照请求 | 2 | 0 |
| 每次快照带花色、点数明细的牌种 | 300 | 1 |

停止滑动后恢复快照、切换选中牌、过滤与隐藏零数量、关闭面板停止轮询均通过。Lua 对照验证总数、未见、已知、手牌、弃牌及选中牌的点数明细一致，且没有读取隐藏牌堆顺序。

这不是 iPhone 真机帧率测量，仍需在原反馈设备和模式中实测。改动先应用于 iOS；Android 当前候选 APK 与 PC 包保持原字节。
