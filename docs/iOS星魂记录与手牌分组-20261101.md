# iOS 星魂记录与已知手牌分组 · 2026-11-01

本批仅处理主站新反馈 [FB-2AA3P9](https://preview.gujianyi-web-preview.pages.dev/feedback/FB-2AA3P9/)（iOS 神姜维星魂）与 [FB-6TYW9M](https://preview.gujianyi-web-preview.pages.dev/feedback/FB-6TYW9M/)（按玩家分类）。两条均未提供具体版本，正文、时间线、空讨论与分组截图已读。另核对全部 19 条反馈讨论，未发现需要合并进本批的新评论。

星魂先把顶牌放入 Processing，再展示、交换、排序并逐张放回。补齐实际可见牌面在确认时的记录，覆盖快速确认及原版先清 popupItem 的关闭顺序；按最终移动建立顺序。精确识别星魂已明确的顶牌移出，保留未受影响的已知牌堆底；任意未知移牌仍保守失效。未读取隐藏牌面、目标暗选结果或服务端牌堆身份。

已知手牌加入横向玩家筛选和玩家分组。使用玩家 ID 区分同名昵称，名称变化保留选中项；更新仍增量修改卡牌模型，不重置滚动位置。失去全部记录的选中玩家退回“全部”；不确定记忆不计入右侧确定数量。
