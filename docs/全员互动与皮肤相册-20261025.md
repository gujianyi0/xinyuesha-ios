# 全员互动、皮肤扫描与相册会话 · 2026-10-25

版本：Android 20261025.2、PC 20261025.1、iOS 20261025.4。实现提交 0eb3314，验证修正 61ff6a4、e7b4d9c。

## 行为

- 聊天→互动，点按“全员砸蛋/全员送花”，取消原来的长按连发。砸蛋排除自己，送花包含房间内自己；旁观/无效编号和重复编号不进入队列。每 1.6 秒发送一人，遵守既有服务端限速。完成或离房取消后共享 10 秒冷却；切房、失去焦点或回放会中止剩余队列。
- 皮肤设置使用独立本地前端，通过运行时菜单元数据路由，服务器包源码和校验边界不变。哈希表线性去重；页面先显示，再每轮最多检查 16 个文件、4 ms 预算。骨骼皮肤缺少任一文件即列入下载，忽略不属于本页或重复的完成信号。
- iOS 相册由完整会话持有原生窗口和弱委托。窗口出现后再展示相册，移除下一轮主线程就认定展示失败的判断。明确取消/确认后释放会话，结果回写所选的大厅/房间/看板娘设置并保存。选图解码与图片导入也纳入测试。
- Android 背景按编码后内容 SHA256 复用文件。普通照片保存 JPEG 90，透明图片保留 PNG；保留方向、SDR 转换、解码/纹理尺寸限制。DEX 只改变压缩方式；原始主 DEX 字节不变，辅助 DEX 因新功能重编译。

- [三端共同回归 40198363732](https://github.com/gujianyi0/xinyuesha-ios/actions/runs/40198363732)：各 60 次生命周期和 6 万条模拟消息，记牌器、好友、战报、语音、鼠标/触摸互动及皮肤扫描测试通过。
- [iOS 40198717231](https://github.com/gujianyi0/xinyuesha-ios/actions/runs/40198717231)：原生 arm64 构建、两套核心前端、背景按钮回写、内容去重，以及实际生产会话的 PhotosUI 取消/重开/选图/确认测试通过。
- 独立 Android API 35 模拟器运行真实图片导入类：EXIF 旋转、40 MP PNG、50 MP 采样边界、SDR、透明度、重复内容地址、压缩和损坏文件保留旧背景全部通过。没有在用户手机安装或退出游戏。
- 4,000 条皮肤的实际 QML 扫描期间仍有 300 多次事件循环心跳；20,002 项实际 Lua 表达式得到 10,000 项去重结果，本机一次约 17 ms。不是原狐狸服真机帧率数据。
- 本批最初检查曾因测试工程缺少 CoreGraphics 链接、断言宏和旧版交互测试预期失败，已修正后重新通过；未发布失败的候选。

## Android 存储调查

仅只读统计当前连接设备的外部应用文件：约 12.01 GiB，其中 packages 约 11.55 GiB、各包 .git 合计约 5.96 GiB，额外皮肤缓存约 414.6 MiB。Git 数字是 packages 的子集，不能相加。比如 fox 约 699.5 MiB，其中 Git 约 391.3 MiB，图片约 205.4 MiB，音频约 70.6 MiB。

APK 从 88,759,987 字节减到 85,221,128 字节，减少约 3.54 MB（以最终 SHA 清单和发布核对为准）。APK 下载体积和手机已下载资源占用不同；本轮背景去重及压缩阻止后续重复增长，并未把现有 12 GiB 扩展资源删掉。Git 对象用于更新和切换服务端指定提交，不能直接当成可丢弃日志删除。切换多个服务器下载的扩展、皮肤会保留以供下次使用；进一步清理既有资源需区分实际使用包、用户修改和可重新下载缓存，不能按文件夹体积自动删除。
