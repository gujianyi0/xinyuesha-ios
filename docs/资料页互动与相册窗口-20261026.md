- [FB-9G8QAS](https://preview.gujianyi-web-preview.pages.dev/feedback/FB-9G8QAS/) 与 [FB-K0B7NM](https://preview.gujianyi-web-preview.pages.dev/feedback/FB-K0B7NM/)：承接此前相册取消、重开与展示失败反馈，以及聊天中新补充的“相册弹出后黑屏无响应”。撤除另建的相册 UIWindow，从现有游戏窗口的可见控制器展示 PhotosUI，保持游戏窗口的可见性、根控制器及焦点；展示未成功时释放忙状态，允许重试。

新增入口只在资料页创建时适配一次。删除每张武将牌的额外监听，不在对局或浏览列表时增加轮询。PC 更新补丁同步刷新被替换文件的时间，避免复用旧 QML 缓存。APK 与 PC 只替换资料页适配和版本标识，保留原生程序、游戏核心、已有皮肤与背景修正；iOS 重新编译原生相册实现。
