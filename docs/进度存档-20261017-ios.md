## 关键决定（不要轻易回退）

- **freekill-core 是文件快照**：iOS runtime 删掉了 `packages/freekill-core/.git`，
  避免被 Git 当成嵌套子模块；`shouldUseCore()` false + packages.db 记录保留，
  核心 Lua 照常加载。

- **强制根目录 UI**：`PackMan::shouldUseCore()` 在 iOS 返回 false。否则会加载
  `packages/freekill-core/Fk/main.qml`（上游原版），card-counter/SocialHost/
  故剑遗全没了。PC 版实际也是根目录；这是把该行为固定下来。
- **运行时复制到 Documents**：iOS `.app` 只读，引擎大量使用相对路径，必须整树
  复制到可写目录；`fk_ver` 最后写，避免半拷贝被当成完整安装。
- **静态链接**：iOS Qt 是静态库；QML 插件通过 `ios/IosImports.qml` +
  `qt_import_qml_plugins` 链入。漏模块会报 `module "QtQuick.Controls" is not
  installed`。
- **Metal**：不强制 OpenGL；`qt_add_shaders` 默认会生成 MSL 12。
